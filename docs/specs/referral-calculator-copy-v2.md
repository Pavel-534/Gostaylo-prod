## 0. Универсальная терминология (агрегатор)

Airento — универсальный агрегатор (недвижимость, транспорт, услуги, аренда яхт и т.п.).  
**Не используем** слова: «поездка», «бронь», «жильё», «путешественник», «турист», «гость» в значении «путешественник».  
**Используем** универсальные: **«заказ»** (вместо «бронь» / «поездка»), **«клиент»** (вместо «гость» / «путешественник»), **«приглашённый»** (вместо «друг»).

Где «гость» — это про кассу/кошелёк клиента → всё равно **«клиент»**.

Исключение: терминология **«Cashback гостю»** исторически закреплена в SSOT (`ReferralUserGuide`/`OwnerGuide`) — оставляем как «Cashback клиенту» в новом макете.

## 7. Acceptance criteria

1. ✅ Простой режим показывает **одну крупную цифру** (ваш итог), без процентов 42/10/5/43.

5. ✅ Кнопка «Что получает клиент?» раскрывает блок про cashback.
6. ✅ Слайдер «Активность L1» — 4 пресета (0% / 33% / 66% / 100%) или плавный 0–100%, default 33%.
7. ✅ Подпись «Суммы в {валюта} по курсу…» — внизу мелко, всегда видна.
8. ✅ L2 cap (500/50 000) — упоминается в подробном режиме, не в простом.
9. ✅ Тесты: существующие `stage131-a5-*` (если есть) + новые snapshot для простого/подробного.
10. ✅ 4 языка: RU/EN/ZH/TH.
11. ✅ **Никаких «поездка / бронь / жильё / путешественник / турист» в UI** — только «заказ» / «клиент» / «приглашённый».
