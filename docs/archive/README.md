# Archive — не SSOT

Исторические аудиты, отчёты, закрытые Stage/планы и **бывший монолитный Architectural Passport**.

| Папка | Содержимое |
|-------|------------|
| `ARCHITECTURAL_PASSPORT_ARCHIVE.md` | Полный текст старого паспорта |
| `audits/` | `AUDIT_*`, RLS/search/user-flow audits |
| `reports/` | `*_REPORT`, Phase D closure, **`TECHNICAL_MANIFESTO_STAGE_LOG.md`** (бывший Stage-хвост манифеста) |
| `stages/` | `STAGE_*` чеклисты и smoke results |
| `plans/` | Закрытые / отложенные планы (YooKassa blueprint, Wave H, Capacitor prep, …) |

**Правила:**

1. Не дописывать новые Stage сюда.  
2. Живые правила — `../CONSTITUTION.md`, карта — `../SYSTEM_MAP.md`, code-truth — `../TECHNICAL_MANIFESTO.md`.  
3. Актуальные планы — `../ROADMAP.md`.  
4. В корне `docs/` оставлены stub на старые имена файлов.

Ещё более старый слой: [`../history/`](../history/README.md).
