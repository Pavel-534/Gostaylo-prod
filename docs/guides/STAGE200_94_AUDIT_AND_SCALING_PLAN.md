## Раздел 2 — План масштабирования: UX-дизайн по всему кабинету

### Принцип

> «Как iPhone» — не значит «как Apple визуально». Это значит: **каждое действие интуитивно, каждая следующая мысль пользователя уже предусмотрена, ничего не обрезано, ничего не сливается, ничего не требует догадок.**

Мы вводим **систему визуального ритма** — единый язык, который масштабируется.

---

### Ядро системы (уже в 200.94)

| Компонент | Назначение | Применено |
|-----------|-----------|-----------|
| `PartnerSectionDivider` | Mint hairline ~20%, mx-4/6, между смысловыми группами | Календарь, Локация |

| Заголовок группы `text-base font-semibold` vs label `text-sm font-medium` | Иерархия | Локация |
| Helper text под input | Связь label↔input | Локация |
| Soft surface + mint accent слева на карточках | Разделение листингов | `/partner/listings` |

### Как проверять: чеклист перед каждым PR

```
□ Padding-bottom: проскроллить до последнего элемента — читается над bottom nav
□ 2+ смысловые группы на экране → mint divider между ними (PartnerSectionDivider)
□ Заголовок группы крупнее label (text-base semibold vs text-sm medium)
□ Helper text под input, не между label и полем
□ Карточки листингов: gap-3 + mint accent слева (или soft surface)
□ Грамматика: нет ошибок в переводах
□ npm run check:brand — чисто
□ npm run check:guest-terminology — чисто
□ Мобильный: 320px и 390px — контент не обрезан нигде
```

---

### Governance: как поддерживать систему

1. **Новые страницы / компоненты** — сразу применять правила из чеклиста
2. **Дизайн-токены** — все spacing/color берутся из `lib/ui/partner-section-rhythm.js` или Tailwind tokens. Никаких magic numbers.
3. **`PartnerSectionDivider`** — импортировать из `components/partner/PartnerSectionDivider.jsx`, не копировать стили вручную
4. **Документация:** обновить `design_guidelines.json` после Фазы 1 (когда система устоится)

Confirmed SSOT for further partner surfaces:

| Token / component | Use when |
|-------------------|----------|
| `PartnerSectionDivider` | Between semantic form groups only |
| `PARTNER_SECTION_TITLE_CLASS` | Group titles (`text-base semibold`) |
| `PARTNER_FIELD_LABEL_CLASS` | Field labels (`text-sm medium`) |

Do **not** put commas inside Tailwind `env()` arbitrary values.
